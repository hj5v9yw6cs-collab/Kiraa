# Кира Горст — сайт-портфолио

Графический дизайнер и модель: айдентика, зины, инфографика, рисунок.
Next.js 15 (App Router) · TypeScript · Tailwind v4 · статическая генерация.
Устроен по той же схеме, что и fedorvoronin: контент в JSON, ru/en, плейсхолдеры в `[скобках]`.

```bash
npm install
npm run dev          # http://localhost:3000
npm run build        # продакшен-сборка
```

`/` редиректит на `/ru`, английская версия — `/en` (переключатель в шапке или клавиша **L**).
Клавиши **1–3** — разделы.

---

## Где лежит контент

Ни одна страница не содержит текста Киры — всё в `/content`:

```
content/
  profile.json            имя, роль, город, статус, «Обо мне», факты, навыки, контакты
  site.json               заголовок, описание, навигация 01–03
  projects/
    chaynyh-del-masterskaya.json   ребрендинг чайной (hero)
    infographics.json              инфографика (с цифрами)
    nana-zine.json                 зин NANA
    business-card.json             визитка дизайнера
    academic-drawing.json          академический рисунок
public/
  media/<проект>/…        картинки проекта
  files/kira-gorst-portfolio.pdf   PDF-портфолио (ссылка «Скачать PDF»)
```

Каждая строка — пара `{ "ru": "…", "en": "…" }`. Если `ru` нет, показывается `en`.

**Всё, что написано `[в квадратных скобках]`, на сайте видно как красная пунктирная плашка** —
так незаполненное никогда не выглядит готовым. Найти все: поиск `[` по `content/`.

### Что сейчас не заполнено

- образование, языки, инструменты — `content/profile.json`;
- год каждого проекта — поле «Год» в `content/projects/*.json`;
- email (`contacts.email` в `profile.json`) — без него форма отдаёт ошибку со ссылкой на Telegram.

## Добавить проект

```bash
npm run new:project -- my-project-slug
```

Создаст `content/projects/my-project-slug.json` с плейсхолдерами и папку `public/media/my-project-slug/`.
Положить картинки, заполнить JSON, удалить `"draft": true`, закоммитить.

| Поле | Что делает |
| --- | --- |
| `index` | Порядок и номер на карточке. |
| `scale: "hero"` | Большой блок на сером размытом поле на главной и сверху `/work`. Один проект. |
| `scale: "standard"` | Колонка картинка/текст, чередуется слева-справа. |
| `scale: "compact"` | Строка в списке «Ещё» (с превью под курсором). |
| `figures` | 3–5 цифр. Первый standard-проект с цифрами получает полосу на главной. |
| `media[].lead` | Картинки первой строки кейса (и hero-карточки), в одну высоту без обрезки. |
| `media[].span` / `start` | Ширина (из 12 колонок) и смещение в галерее кейса. |
| `blocks` | Текстовые блоки кейса: `text`, `list`, `steps`, `quote`. |

У каждой картинки нужны `width` и `height` — они резервируют место, чтобы страница не прыгала:

```bash
python3 -c "from PIL import Image; print(Image.open('file.jpg').size)"
```

## Форма обратной связи

`app/api/contact/route.ts` отправляет письма через [Resend](https://resend.com).

```bash
cp .env.example .env.local   # RESEND_API_KEY, CONTACT_TO, CONTACT_FROM
```

Без ключей форма честно показывает ошибку и ссылку на Telegram. Лимит — 5 сообщений в минуту с IP.

## Деплой

Импортировать репозиторий на [vercel.com/new](https://vercel.com/new), добавить переменные из
`.env.example` и `NEXT_PUBLIC_SITE_URL=https://ваш-домен` (для sitemap, canonical и OG-картинки).
Дальше каждый коммит в `main` выкладывается автоматически — JSON и картинки можно править прямо
в веб-интерфейсе GitHub.

## Дизайн-система

Фон — холодная серая бумага (`#e6e6e3`), как серые плашки в PDF-портфолио Киры; чернила — почти
чёрный `#0f0f10`. Один акцент — малиновый из зина NANA (`#d0135a`): статус, активный пункт меню,
фокус и плейсхолдеры. Размытое серое поле со страниц-разделителей PDF — фон hero-проекта и цитат.
Шрифты: **Unbounded** (широкий, только заголовки, капсом), **Onest** для текста,
**JetBrains Mono** для метаданных — все с кириллицей. Анимации: Lenis + `.reveal` / `.line-mask`,
всё выключается при `prefers-reduced-motion`.
